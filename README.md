# Mohamed Abbas Pricing
Arabic RTL pricing website: HTML5, CSS3, vanilla JS. Developed by Mohamed Ahmed Abbas.

Run locally: `python3 -m http.server` then open http://localhost:8000
GitHub Pages: push this folder to a repo, Settings > Pages > Deploy from branch (main, root).

Features: animated hero and counters, service ticker, tabs with transitions, scroll reveal, search, 3D card tilt, quote builder (select packages, total, copy summary). Respects prefers-reduced-motion and dark mode.

Testing summary: JS syntax checked with node (if reported below). Skill validation scripts and browser screenshots were NOT run (not available). Visual comparison was not performed.
